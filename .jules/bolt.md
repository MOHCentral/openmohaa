## 2024-10-14 - Semantic Difference between strlen Loop and strchr
**Learning:** In C, replacing a `for (i = 0; i < strlen(set); i++)` loop checking for character matches with a fast O(1) `strchr(set, c)` call introduces a subtle semantic difference if not careful. `strchr` successfully matches the null terminator `\0`, whereas the `strlen`-based loop condition strictly excludes it. Without explicitly checking for `\0` first (e.g. `if (c == '\0') return qfalse;`), this optimization can lead to unintentional matches on the null terminator and potentially cause infinite loops in parser or tokenizer logic.
**Action:** When migrating from `strlen`-bounded searches to standard `str*()` search functions for optimization, always explicitly verify if the original logic excluded the null terminator and explicitly reject it if needed.
