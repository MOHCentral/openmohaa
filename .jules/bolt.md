## 2024-05-24 - [Replace O(N^2) strlen loop with strchr in Field_FindFirstSeparator]
**Learning:** Found a classic O(N^2) bottleneck in `Field_FindFirstSeparator` where `for (i = 0; i < strlen(s); i++)` was used to find a semicolon. The compiler cannot always hoist `strlen` out of the loop because of potential aliasing or side effects, making string processing needlessly expensive for large strings. Using standard library functions like `strchr` natively handles this in O(N).
**Action:** Replace manual `strlen()` checks in character search loops with optimized standard C library functions like `strchr()` for O(1) loop conditions (or rather O(N) overall instead of O(N^2)), while keeping in mind that `strchr` handles the null terminator, so the behavior is equivalent for searching actual characters like `';'`.
