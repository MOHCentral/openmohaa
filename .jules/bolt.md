## 2024-05-24 - [Avoid `strlen` in loop conditions and watch out for `strchr` matching `\0`]
**Learning:** Calling `strlen` in a `for` loop condition creates an O(N^2) operation because the length is recalculated every iteration, and the compiler often cannot optimize it away. When replacing a manual loop that searches for characters in a charset with `strchr`, we must remember that `strchr(set, '\0')` successfully returns a pointer to the null terminator. The old `i < strlen(set)` loop explicitly avoided matching the null terminator.
**Action:** Always cache `strlen` outside loop conditions, or use O(1) library lookups like `strchr` if searching for a character. When making the swap to `strchr`, explicitly verify `c == '\0'` first (e.g., `if (c == '\0') return qfalse;`) if the original behavior didn't match the null terminator.
