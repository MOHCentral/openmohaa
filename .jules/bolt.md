## 2025-02-18 - Replacing strlen with strchr in loops
**Learning:** When optimizing character search loops like `for(i=0; i<strlen(set); i++) { if(set[i]==c) return qtrue; }` to an O(1) `strchr(set, c) != NULL` call, you must consider the null terminator `\0`. The original `strlen` loop only checks up to, but not including, the null terminator. `strchr`, however, treats the null terminator as part of the string. If `c == '\0'`, the original loop would return false, but `strchr(set, c)` would return a valid pointer (true). This can cause infinite loops or different behavior in parsers skipping characters.
**Action:** Always add an explicit null check (`if (c == '\0') return qfalse;`) before delegating to `strchr` when replacing `strlen`-bounded loops for character finding.
